# TOUCHLINE 26 90초 시연 스크립트

> 영상 촬영·YouTube 업로드·공개 접근 확인은 **사용자 작업 필요**입니다.
> 완성된 YouTube URL은 배포 URL·GitHub URL과 함께 DAKER에 입력하는 세 URL 중
> 하나이며, 영상 파일 자체를 DAKER에 업로드하지 않습니다.

## 한 문장 메시지

TOUCHLINE 26은 2026 월드컵 A조 4개국의 실제 여섯 경기를 13개 전술 미션으로 다시 판단하고, 세 경기의 선택을 국가별 감독 리포트로 돌아보는 회고형 시뮬레이션입니다.

## 촬영 환경

- production URL
- 영상 출력 1920×1080 권장, 최소 1280×720, 30fps 이상
- 앱 viewport 1280×720 이상, 브라우저 확대 100%
- 개인정보, 북마크 바, 확장 프로그램 팝업, 개발자 도구 숨김
- 첫 미션 시연용 새 세션
- 완성 리포트 컷을 함께 찍을 경우, 별도 브라우저 프로필에서 한 국가의 앞선
  결정들을 정상 UI로 미리 완료한 시연 세션
- 클릭 조작을 주 흐름으로 사용
- 드래그앤드롭은 실제 데스크톱 브라우저에서 시작·드롭·취소를 검증한 경우에만
  짧은 보조 시연으로 사용하고, 미검증이면 영상에서 생략
- 최종 공개 main tip의 저장소 루트 Next.js 앱 사용
- Git이 무시하는 로컬 `python-fastapi/` 참고 복사본은 촬영·제출에 사용하지 않음

작은 데이터 안내와 점수 구성은 빠르게 스크롤하지 말고 최소 1초 정지해
읽을 수 있게 합니다. 그래도 글자가 작다면 편집 단계에서 해당 영역을
크롭·확대하되 문맥이 사라지지 않게 섹션 제목을 함께 남깁니다. 클릭 선택을
주 흐름으로 촬영하고 드래그 시연 때문에 핵심 결과·리포트 장면을 줄이지
않습니다.

## 90초 타임라인

| 시간 | 화면과 조작 | 내레이션 |
| --- | --- | --- |
| 0–7초 | 홈에서 범위와 `국가 선택` CTA | “TOUCHLINE 26은 월드컵 A조 실제 경기를 다시 판단하는 회고형 감독 시뮬레이션입니다.” |
| 7–15초 | `/teams`에서 KOR/CZE/MEX/RSA 네 카드 확인 후 한 국가 선택 | “대한민국, 체코, 멕시코, 남아공 네 나라와 A조 여섯 경기, 모든 경기의 양 팀 감독 관점을 지원합니다.” |
| 15–23초 | 국가 페이지의 3경기 여정과 진행률, 리포트 버튼 | “한 국가를 고르면 세 경기 여정을 따라갑니다. 전체 13개 미션 중 이 팀의 진행률도 기기에 저장됩니다.” |
| 23–32초 | 첫 미션 브리핑의 현재 점수·직전 사건·라인업 | “브리핑에는 이 선택 시점까지 확인할 수 있던 공식 사실만 보입니다. 이후 사건과 실제 선택은 아직 숨깁니다.” |
| 32–47초 | OUT 선수, IN 선수, 역할을 클릭하고 팀 지시 변경 | “선수를 클릭해 교체하고 역할, 공격 방향, 압박, 수비 라인, 성향을 정합니다. 클릭이 주 조작이라 모바일에서도 같은 흐름입니다.” |
| 47–57초 | 현재 경기 상태·전술 역할 비교와 데이터 안내 카드 | “최근 1년 공통 성과 데이터는 만들지 않았습니다. BASE는 0/104명, 0/832 속성이고 Form과 리그 보정도 미적용입니다. 컨디션은 공식 출전 시간 기반 추정입니다.” |
| 57–67초 | 적합도와 `점수 구성 보기`, 장점·위험 변화 | “전술 선택 적합도는 포지션, 역할, 지시와 경기 상황의 일관성을 설명합니다. 승률이나 선수 절대 능력치가 아닙니다.” |
| 67–78초 | 결정 확정 후 결과 화면을 아래로 이동 | “확정 뒤에 선택 요약과 점수 구성, 예상 장점과 위험을 먼저 보고, 공식 경기 사실과 실제 감독 선택은 결과 전용 정보로 구분해 비교합니다.” |
| 78–85초 | 사전 준비한 시연 세션의 `/teams/[teamId]/report`로 전환해 3경기 완료 리포트·감독 성향·다시 플레이 | “리포트는 같은 경기의 미션을 먼저 평균하고 세 경기를 같은 비중으로 봅니다. 역할과 팀 지시 패턴으로 감독 성향을 설명합니다.” |
| 85–90초 | `/teams`의 4개국 지원 화면으로 돌아가 TOUCHLINE 26 이름과 실제 production URL을 주소창 또는 편집 오버레이로 표시 | “다른 국가의 세 경기에도 도전할 수 있습니다. TOUCHLINE 26은 이 공개 주소에서 바로 실행됩니다.” |

리포트 컷은 미리 계산값을 주입하지 않습니다. 촬영 전에 선택한 국가의 3경기를
실제 UI로 완료하고, 마지막 결정을 확정해 전체 평균이 나타나는 과정까지 확인한
브라우저 프로필을 사용합니다. 시간상 사전 완료가 어렵다면 부분 리포트를 보여주고
“전체 평균은 세 경기 완료 뒤 표시”라고 정확히 설명합니다.

## 촬영 중 반드시 보일 것

- [ ] 선택 국가의 3경기 여정과 진행률

- [ ] 전술 선택 적합도와 동적 점수 구성
- [ ] “승률·선수 절대 능력치 아님” 안내
- [ ] 최근 1년 비교 지표가 없다는 단일 데이터 안내
- [ ] 출전 시간 기반 컨디션 추정 표시
- [ ] 결과 화면에서 공식 사실·자체 분석·결과 전용 사실 구분
- [ ] 경기 동일 비중의 국가별 리포트
- [ ] 결정 기반 감독 성향과 다시 플레이

## 정확한 표현

사용할 표현:

- “회고형 전술 의사결정 시뮬레이션”
- “전술 선택 적합도”
- “프로젝트 자체 규칙에 따른 설명값”
- “출전 시간 기반 컨디션 추정”
- “확보하지 못한 최근 1년 선수 성과 지표는 미산정”
- “실제 감독 선택은 정답이 아니라 비교 자료”
- “현재 브라우저에 저장한 최소 선택을 검증하고 재계산”

사용하지 않을 표현:

- “승률”, “승리 예측”, “AI가 계산한 정답”
- “FIFA 공식 능력치” 또는 “공식 선수 평점”
- “최근 1년 통계로 104명을 완전 평가”
- “BASE의 0이 선수 능력 0”
- “Form이 적용됐다” 또는 “TLSI가 리그 강도를 검증했다”
- “에너지 수치가 실제 체력·의료 데이터”
- “실제 감독 선택이 정답”
- “모든 주요 브라우저 검증 완료” — 실제 확인 전
- “공개 배포·GitHub·YouTube 제출 완료” — 실제 URL 확인 전
- 공식 기관과의 승인·후원·제휴를 암시하는 표현

## YouTube 업로드 체크

- [ ] 영상 길이와 해상도가 대회 제출 조건에 맞음
- [ ] 음성 또는 자막으로 작은 화면 문구를 이해할 수 있음
- [ ] 공개 또는 대회가 허용하는 미등록 설정이며 비공개가 아님
- [ ] 로그아웃·시크릿 창에서 처음부터 끝까지 재생
- [ ] 저작권 문제가 있는 음악, 선수 사진, 경기 방송 영상이 없음
- [ ] 영상 설명에 실제 production URL과 공개 GitHub URL 입력
- [ ] 영상 안에서 production 주소와 핵심 선택·결과 화면 확인
- [ ] YouTube URL을 `SUBMISSION_RELEASE_CHECKLIST.md`와 제출 폼에 동일하게 입력

현재 YouTube URL은 생성되지 않았으므로 완료 표시하지 않습니다.
