# TOUCHLINE 26 시연 영상 스크립트

## 촬영 목표

심사자가 90초에서 2분 안에 다음을 명확히 이해하도록 한다.

- 실제 2026 월드컵 데이터를 사용한다.
- 사용자가 감독으로 직접 교체와 전술을 결정한다.
- 역할과 팀 지시가 점수·영향·위험을 바꾼다.
- 실제 감독 선택은 정답이 아니라 비교 자료다.

권장 촬영 크기: 1280×720. 브라우저 확대 100%, 개인정보·개발자 도구·북마크 바를 숨긴다.

## 90초 버전

| 시간 | 화면/조작 | 내레이션 초안 |
|---|---|---|
| 0–7초 | 홈 첫 화면. “실제 2026 월드컵 데이터” 배지와 69분 1–1 패널 | “가장 높은 선수가 아니라, 지금 이 경기에 가장 필요한 선수를 고릅니다. TOUCHLINE 26입니다.” |
| 7–14초 | `감독 미션 시작` 클릭, 대한민국 2–1 체코 카드 | “FIFA 공식 리포트로 검증한 실제 대한민국–체코전입니다.” |
| 14–22초 | 경기 카드 → 첫 미션 → 브리핑 | “69분 1대1. 동점의 흐름을 살려 박스 안 한 칸을 바꾸는 미션입니다.” |
| 22–36초 | 전술 보드에서 손흥민 클릭, 오현규 클릭 또는 드래그 | “필드에서 OUT, 벤치에서 IN을 고릅니다. 모바일에서는 같은 흐름을 클릭으로 수행할 수 있습니다.” |
| 36–47초 | 선수 비교의 1–20 스탯, 신뢰도·표본 분 강조 | “이 숫자는 게임 능력치가 아니라 공식 경기 데이터를 포지션과 표본 신뢰도로 보정한 회고 지표입니다.” |
| 47–60초 | 타깃형 공격수 선택, 중앙 공격/높은 압박 등 팀 지시 변경 | “역할과 팀 지시를 바꾸면 상황 적합도와 공격·점유·압박·수비 게이지가 즉시 변합니다.” |
| 60–68초 | 위험 경고와 교체 미리보기, 결정 확정 | “장점만 보여주지 않고 라인과 압박의 모순, 낮은 표본 같은 위험도 함께 계산합니다.” |
| 68–82초 | 결과 점수, 장점, 위험, 보완책, 영향 전후 | “결과는 승패 예측이 아니라 현재 미션과의 적합도입니다. 높은 점수에도 반드시 위험과 보완책이 있습니다.” |
| 82–90초 | 실제 감독 선택 비교와 다음 미션 버튼 | “실제 감독의 선택은 정답으로 판정하지 않고, 확인된 사실과 전술적 추론을 나눠 비교합니다.” |

## 2분 버전

| 시간 | 화면/조작 | 내레이션 초안 |
|---|---|---|
| 0–10초 | 홈 히어로와 네 단계 설명 | “TOUCHLINE 26은 실제 월드컵의 결정적 순간을 다시 판단하는 감독 시뮬레이션입니다.” |
| 10–22초 | 경기 선택 카드의 날짜·장소·스코어·검증 배지 | “첫 경기는 2026년 6월 11일 대한민국 2대1 체코. 선발, 벤치, 교체, 선수 지표를 FIFA 공식 자료와 독립 출처로 확인했습니다.” |
| 22–36초 | 경기 상세에서 두 미션 비교 | “동점을 깨는 69분과 리드를 닫는 84분은 필요한 선수가 다릅니다.” |
| 36–50초 | 첫 미션 브리핑 타임라인과 관찰 정보 | “체코가 59분 득점했고 황인범이 67분 동점을 만들었습니다. 상대는 5백을 유지합니다.” |
| 50–67초 | 손흥민 OUT → 오현규 IN 드래그, 클릭 대체도 짧게 시연 | “벤치 선수를 필드 선수 위로 드롭하거나, 필드와 벤치를 차례로 클릭합니다.” |
| 67–82초 | 비교 패널, 역할 선택 | “오현규는 박스 타깃과 막판 임팩트가 강하지만 28분 표본이라 신뢰도 보정을 받습니다.” |
| 82–98초 | 팀 지시 여러 조합 변경, 위험 경고 확인 | “중앙 공략, 높은 압박, 수비 라인을 조합하면 점수와 네 게이지가 실시간으로 바뀝니다. 높은 라인과 낮은 압박은 별도 위험입니다.” |
| 98–112초 | 결과 리포트 상단과 장점·위험·보완책 | “결과는 선택의 이유, 위험, 보완책, 대안까지 규칙 기반으로 설명합니다. 생성형 API나 키가 필요 없습니다.” |
| 112–120초 | 실제 선택 비교, `다음 미션` | “실제 감독도 손흥민 대신 오현규를 투입했지만 그것을 정답으로 보지는 않습니다. 이제 84분 리드 보호 미션으로 이어집니다.” |

## 반드시 보여줄 기능

- [ ] 홈의 실제 데이터·감독 역할·교체 핵심 문구
- [ ] 실제 경기 카드의 검증 상태
- [ ] 69분 1–1 미션 브리핑
- [ ] 필드 선수 선택
- [ ] 벤치 선수 선택 또는 드래그
- [ ] OUT/IN 미리보기와 취소
- [ ] 선수 1–20 지표, 표본 분, 신뢰도
- [ ] 역할 선택
- [ ] 팀 지시 변경
- [ ] 상황 적합도와 네 영향 게이지 변화
- [ ] 모순 전술 위험 경고
- [ ] 결과 점수, 장점, 위험, 보완책, 대안
- [ ] 실제 감독 선택의 사실/추론 구분
- [ ] 다음 미션

## 촬영 전 체크리스트

- [ ] production URL을 새 시크릿 창에서 연다.
- [ ] 브라우저 콘솔 오류가 없는지 확인한다.
- [ ] 1280×720에서 오른쪽 결정 버튼까지 보이는지 확인한다.
- [ ] 저장된 이전 선택을 삭제하고 시작한다.
- [ ] 마우스 드래그와 클릭 흐름을 각각 한 번 연습한다.
- [ ] 결과로 이동하기 전 역할을 반드시 선택한다.
- [ ] 팀 지시를 바꿔 점수와 게이지 변화가 화면에 보이게 한다.
- [ ] 화면에 개인 정보·토큰·로컬 경로가 보이지 않게 한다.
- [ ] 영상 설명에 배포 URL과 GitHub URL을 넣는다.
- [ ] YouTube 공개 또는 일부 공개 링크를 로그아웃 상태에서 확인한다.
