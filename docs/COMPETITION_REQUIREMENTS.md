- 확인 일시: 2026-07-27 12:18 KST (UTC+09:00)
- 대회 안내: https://daker.ai/public/hackathons/world-cup-manager-tactics-web-challenge
- 확인 방법: 공개 대회 안내 페이지 직접 열람
- 추가 공지: 안내 페이지는 운영진 추가 공지가 있을 경우 최신 공지를 우선한다고 명시한다. 현재 별도 게시판 공지는 이 문서에 반영하지 못했으므로 제출 직전에 다시 확인한다.
- 시간대 주의: 페이지에 마감 시각은 표시되어 있으나 시간대 표기는 별도로 확인되지 않았다. 운영사와 서비스 맥락상 KST로 보이지만, 최종 제출 전 게시판에서 확정한다.

## 핵심 목표

실제 2026 FIFA 월드컵 데이터를 활용해 사용자가 감독처럼 선수 배치와 전술을 직접 클릭·드래그·조작하는 동적 웹서비스를 설계, 구현, 공개 배포한다. 심사는 설명 문서가 아니라 실제 배포 URL의 작동 상태를 중심으로 진행된다.

## 배포 조건

- 웹 브라우저에서 별도 설치 없이 플레이할 수 있어야 한다.
- 외부에서 접속 가능하고 심사 기간 동안 유지되는 HTTPS URL이어야 한다.
- 회원가입과 유료 결제 없이 심사할 수 있어야 한다.
- 주요 브라우저에서 핵심 사용자 흐름이 정상 작동해야 한다.
- 외부 API를 쓰더라도 심사자가 별도 키를 입력하지 않아야 한다.
- 본 프로젝트는 외부 API 없이 정적 데이터만으로 핵심 흐름을 완성하고 Vercel 배포를 기준으로 구성한다.

## 시연 영상 조건

시작 화면, 선수 배치와 전술 설정, 클릭·드래그 등 핵심 인터랙션, 결과 화면을 포함해 서비스의 전체 흐름이 보여야 한다. 본 프로젝트는 90초와 2분 버전 촬영 스크립트를 별도로 제공한다.

## 인터랙션 조건

- 정적 페이지나 이미지가 아니라 실제 작동하는 동적 웹서비스여야 한다.
- 사용자가 직접 클릭, 드래그, 선수 배치, 전술 설정을 수행해 감독 경험을 느낄 수 있어야 한다.
- 선언만 되어 있고 실제 작동하지 않는 기능은 평가에서 제외될 수 있다.
- 모바일에서는 드래그 외에 선수 선택 버튼을 통한 동등한 교체 흐름을 제공한다.

## 데이터 조건

- 주제상 실제 2026 월드컵 데이터를 사용해야 한다.
- 경기, 스코어, 명단, 교체 시점은 신뢰 가능한 공개 출처로 확인한다.
- 확인된 사실과 전술적 해석, 앱이 산출한 파생 점수를 명확히 구분한다.
- 앱의 1~20 값은 게임 데이터베이스 능력치가 아니라 출처가 명시된 경기·대회 퍼포먼스 자료를 설명 가능한 규칙으로 변환한 지표다.
- 데이터가 불충분한 항목은 임의의 실제 정보처럼 만들지 않고 누락 또는 제한을 명시한다.

## 외부 API 조건

- 외부 API 사용은 허용되지만 심사자가 별도 키 없이 결과를 확인할 수 있어야 한다.
- 키가 필요한 기능은 평가에서 확인이 제한될 수 있다.
- MVP는 생성형 AI API, 실시간 경기 API, 외부 백엔드 없이 작동한다.

## 저작권·라이선스 조건

- 코드, 이미지, 폰트, 아이콘을 포함한 모든 제출 자산의 저작권과 라이선스를 준수한다.
- 타인의 결과물 무단 복제·도용 또는 라이선스 위반은 실격·감점 사유다.
- 특정 선수·팀·국가를 비하하거나 명예를 훼손하는 표현은 금지한다.
- FIFA 공식 로고·엠블럼·대회 그래픽과 선수 사진은 사용하지 않는다.
- Football Manager/FMM의 화면 구성, 고유 디자인, 문구, 아이콘, 폰트, 선수 카드, 게임 자산을 복제하지 않는다.
- UI는 텍스트, CSS 도형, 자체 제작 축구장과 선수 토큰으로 구성한다.
